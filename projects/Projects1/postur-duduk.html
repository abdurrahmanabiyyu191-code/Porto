Sistem Pemantauan Postur Duduk Cerdas

RANCANG BANGUN DETEKSI POSTUR DAN LAMA DUDUK UNTUK KESEHATAN MENGGUNAKAN ALGORITMA RANDOM FOREST

ESP32 Random Forest Python Firebase Realtime DB

Deskripsi Proyek

Duduk terlalu lama dengan posisi tubuh yang buruk dapat menyebabkan gangguan kesehatan tulang belakang (musculoskeletal disorders). Proyek ini dirancang untuk memantau posisi duduk seseorang secara real-time menggunakan jaringan sensor terintegrasi dengan mikrokontroler ESP32. Data posisi diolah dengan algoritma Machine Learning untuk mendeteksi kebiasaan duduk tidak sehat dan memberikan peringatan otomatis.

Fitur Utama

  • Klasifikasi Postur Real-time: Membedakan posisi duduk ideal, membungkuk, miring kanan/kiri.
  • Pelacakan Durasi Duduk: Peringatan otomatis jika pengguna duduk tanpa jeda melebihi ambang batas aman.
  • Akurasi Tinggi: Klasifikasi berbasis Machine Learning (Random Forest) untuk presisi deteksi.
  • Integrasi Cloud: Penyimpanan log data kesehatan duduk secara terpusat di Google Firebase.

Spesifikasi Teknis

Mikrokontroler: ESP32 (Wi-Fi & Bluetooth Dual Core)

Machine Learning: Random Forest Classifier

Database: Firebase Realtime Database

Bahasa Pemrograman: C++ (Arduino IDE) & Python (Data Analysis/Training)

Detail Rangkaian & Hardware

1. Kelistrikan Pada Alat Wiring

Deskripsi Rangkaian: Rangkaian ini meggunakan ESP 32 Sebagai otak pada alat untuk menerima input dari sensor FSR memprogres data sesuai ketentuan yang dibuat dan dan mengirimkan output ke Dasboard Web

  • input = 8 Sensor FSR
  • Progres = ESP 32
  • Output = Dashboard Web

2. Skematik dan Design 3D Pada PCB / Postur PCB

Deskripsi Rangkaian: Komponen yang digunakan disatukan dengan PCB untuk mengurangi perkabelan dan estetika pada alat.

  • Menggunakan Software Easyeda
  • Terhubung ke pin ESP32 (misal: GPIO32, GPIO33, GPIO34, GPIO35).

3. Design Mekanik,Penguian alat dan Dashboar web Sensor Layer

Deskripsi Rangkaian: Sensor-sensor pembaca diletakkan pada titik-titik tumpuan utama alas dan sandaran kursi. Pembacaan nilai analog dikonversi oleh pin ADC ESP32 sebagai input model Random Forest.

  • Menggunakan rangkaian pembagi tegangan (voltage divider) dengan resistor presisi.
  • Terhubung ke pin ADC ESP32 (misal: GPIO32, GPIO33, GPIO34, GPIO35).
